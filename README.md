# DivaSenseHaptics

Hatsune Miku Project diva mega mix + mod with PS5 dualsense controller

## Description

Haptics response for music, and corresponding note press, menu selections. Only work with wired DualSense.
Should work with other mods, I have download 100+ mods and no conflicts. Put this to piority if no effect.

## Requirements

- DIVA Mod Loader.
- DualSense or DualSense Edge(not tested) connected by a **data-capable USB cable**.


## Build

Open a **Developer PowerShell for Visual Studio 2022** in the repository and run:

```powershell
.\scripts\package.ps1 -Configuration Release
```
