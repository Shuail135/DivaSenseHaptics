# DivaSenseHaptics

Hatsune Miku Project diva mega mix + mod with PS5 dualsense controller

## Description

Haptics response for music, and corresponding note press, menu selections. Only work with wired DualSense.
The code is originally generated by AI, and it is absolutely terrible(how does it work actually).
I took the working part out, remove a lot of questionable code(why use screen detect??)
Still in prgress


## Requirements

- DIVA Mod Loader.
- DualSense or DualSense Edge(not tested) connected wired.


## Build

Open a **Developer PowerShell for Visual Studio 2022** in the repository and run:

```powershell
.\scripts\package.ps1 -Configuration Release
```
